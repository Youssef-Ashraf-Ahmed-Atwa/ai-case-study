# 15. Fraud Detection Using ML in Digital Banking

## 1. Project / Case Study
- **Project title:** Fraud Detection Using ML in Digital Banking
- **Source repository:** `ai-case-study`
- **Source filename:** `Fraud_Detection Using ML in Digital Banking.pdf`

## 2. Business Problem
Digital banking growth increases fraud exposure while customers still expect real-time, low-friction transactions. Rule-only detection either misses sophisticated fraud or blocks legitimate activity excessively.

## 3. AI/ML/Analytics Solution
The case proposes machine-learning fraud scoring using multi-source signals (transaction, device, behavior, authentication) to detect suspicious patterns faster and prioritize investigation actions.

## 4. Business Value and Information Systems / ERP / Digital Transformation Link
Expected value is lower fraud losses with better customer experience balance (security vs friction). IS/ERP relevance appears through integration with payment engines, case-management systems, and feedback loops for model improvement.

## 5. Exam-ready answer
This case explains why fraud management in digital banking needs adaptive analytics. The business problem is dual: prevent financial loss while preserving smooth customer transactions. Traditional static rules struggle with evolving attack patterns and context complexity. ML-based detection can score transaction risk in near real time using cross-channel evidence, then trigger proportional controls such as step-up verification or analyst review. The strategic advantage is not only better detection but also smarter prioritization of investigation resources. In digital-transformation terms, success requires closed-loop integration between detection models, fraud operations, and customer channels so decisions are fast, explainable, and continuously improved.

## 6. Keywords
Fraud analytics, ML risk scoring, digital payments, false positives, case management, banking security
