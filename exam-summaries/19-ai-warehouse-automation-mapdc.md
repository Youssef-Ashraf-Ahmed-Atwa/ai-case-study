# 19. AI-Based Warehouse Automation (MAPDC Case)

## 1. Project / Case Study
- **Project title:** AI-Based Warehouse Automation (MAPDC Case)
- **Source repository:** `ai-case-study-2`
- **Source filename:** `MAPDC_AI_Warehouse_Automation_Final_Presentation.pptx`

## 2. Business Problem
High-volume spare-parts warehouses face picking inefficiency, routing/slotting rigidity, and weak predictive control despite having ERP/WMS transactions. Manual and rule-based operations leave value unrealized.

## 3. AI/ML/Analytics Solution
The MAPDC case designs an AI-enabled warehouse model combining predictive decisioning for storage/routing and process simulation. It explicitly states that MAPDC and numeric outcomes are modeled academic assumptions, not measured production results.

## 4. Business Value and Information Systems / ERP / Digital Transformation Link
Expected value is lower handling cost, better fulfillment speed, and improved operational control. Digital value depends on AI-WMS-ERP interoperability so model decisions can be executed and monitored end-to-end.

## 5. Exam-ready answer
The MAPDC project presents warehouse AI as an execution challenge, not just an algorithm challenge. The business issue is that transaction systems record activity but do not optimize physical flows in real time. The proposed solution adds predictive logic for slotting and picking decisions, supported by simulation to test operational scenarios before rollout. Importantly, the case clarifies that it is a fictional/simulated study, so benefits are presented as expected rather than measured outcomes. In exam analysis, this strengthens methodological rigor: assumptions are transparent, and value is tied to system integration with ERP/WMS processes. The digital-transformation takeaway is moving from descriptive warehouse reporting to AI-assisted operational orchestration.

## 6. Keywords
Warehouse automation, WMS, ERP integration, picking optimization, simulation, modeled assumptions
